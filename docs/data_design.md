#　測定データ設計

## 説明

本資料では、測定結果を CSV 出力する際のデータ項目、データ型、および各項目の説明を示しています。
一部の機能は現在実装中であり、最新の実装状況については README の「開発状況」を参照してください。

## CSV 出力仕様

- 1 行につき 1 ラインの測定結果を出力します。
- 測定完了後、CSV ファイルを生成します。
- Web アプリでは、この CSV ファイルを取り込み、測定履歴を管理します。

## CSV 出力項目

| 項目           | 型       | 説明                       |
| -------------- | -------- | -------------------------- |
| 日時           | DateTime | 測定日時                   |
| 装置名         | string   | Device01/Device02          |
| ウェーハ ID    | string   | ウェーハ ID                |
| Lot            | string   | ロット番号                 |
| レシピ名       | string   | レシピ名                   |
| 品番           | string   | 製品名                     |
| ウェーハ種類   | string   | PW/CW/LW/SW                |
| 作業者         | string   | 作業者                     |
| 測定ライン数   | int      | 3/5/9                      |
| ライン番号     | int      | 現在の測定のライン番号     |
| ライン位置     | int      | 測定位置(mm)               |
| ライン平均膜厚 | double   | 測定値(μm)                 |
| 全体平均膜厚   | double   | ライン平均膜厚の平均値(μm) |
| 上限値         | double   | レシピの上限(μm)           |
| 下限値         | double   | レシピの下限(μm)           |
| 全体判定       | string   | OK/NG                      |
