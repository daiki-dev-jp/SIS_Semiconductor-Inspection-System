#　テスト仕様書

## 説明

本資料では、主要機能のテスト項目と期待結果を示しています。
一部の機能は現在実装中であり、最新の実装状況については README の「開発状況」を参照してください。

## テスト仕様書

### デスクトップアプリ

#### 画面表示テスト

| No  | テスト内容                        | 操作                                              | 期待結果                                                                                                                                 |
| --- | --------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | レシピ一覧表示                    | アプリケーションを起動する                        | 登録済みのレシピがコンボボックスに一覧表示される。                                                                                       |
| 2   | レシピ選択                        | コンボボックスからレシピを選択する                | 選択したレシピの情報がメイン画面に表示される。                                                                                           |
| 3   | レシピ追加後の表示                | レシピを新規登録する                              | 保存したレシピがコンボボックスに追加され、自動的に選択される。                                                                           |
| 4   | レシピ編集後の表示                | レシピを編集して保存する                          | 編集内容がメイン画面に反映される。                                                                                                       |
| 5   | レシピ削除後の表示                | レシピを削除する                                  | 削除したレシピがコンボボックスから削除される。                                                                                           |
| 6   | 必須入力チェック                  | 必須項目（ウェーハ ID・Lot 番号）未入力で保存する | エラーメッセージが表示され、保存されない。                                                                                               |
| 7   | ウェーハ ID・Lot 番号入力チェック | 半角英数字・ハイフン以外の文字を入力して保存する  | エラーメッセージが表示され、保存されない。                                                                                               |
| 8   | 作業者入力チェック                | 半角英数字・ハイフン以外の文字を入力して保存する  | エラーメッセージが表示され、保存されない。                                                                                               |
| 9   | IDLE 状態の画面表示               | アプリケーションを起動する、またはリセットする    | 「情報送信」ボタンのみ活性、「測定開始」「リセット」ボタンは非活性となる。                                                               |
| 10  | READY 状態の画面表示              | 「情報送信」ボタンを押下する                      | 「測定開始」ボタンのみ活性、「情報送信」「リセット」ボタンは非活性となる。                                                               |
| 11  | START 状態の画面表示              | 「測定開始」ボタンを押下する                      | 「情報送信」「測定開始」「リセット」ボタンがすべて非活性となる。                                                                         |
| 12  | COMPLETE 状態の画面表示           | 測定シミュレーションを完了する                    | 「リセット」ボタンのみ活性、「情報送信」「測定開始」ボタンは非活性となる。                                                               |
| 13  | ERROR 状態の画面表示              | 異常を発生させる                                  | 「リセット」ボタンのみ活性、「情報送信」「測定開始」ボタンは非活性となる。                                                               |
| 14  | リセット後の画面初期化            | 「リセット」ボタンを押下する                      | 状態が IDLE に戻り、入力欄・測定結果テーブル・エラーメッセージが初期状態となる。                                                         |
| 15  | 測定結果表示                      | 「測定開始」ボタンを押下し、測定を正常に完了する  | 測定結果テーブルに測定結果が表示される。各行に測定点番号、平均膜厚、判定が正しく表示され、測定点数は選択したレシピのライン数と一致する。 |

#### レシピ機能テスト

| No  | テスト内容             | 操作                                       | 期待結果                                   |
| --- | ---------------------- | ------------------------------------------ | ------------------------------------------ |
| 1   | レシピ新規登録         | 必要項目を入力して保存する                 | レシピが JSON ファイルへ保存される。       |
| 2   | レシピ編集             | レシピを編集して保存する                   | レシピ情報が更新される。                   |
| 3   | レシピ削除             | 削除ボタンを押下する                       | レシピが削除される。                       |
| 4   | 必須入力チェック       | 必須項目（レシピ名・品番）未入力で保存する | エラーメッセージが表示され、保存されない。 |
| 5   | レシピ名重複チェック   | 重複したレシピ名で保存する                 | エラーメッセージが表示され、保存されない。 |
| 6   | 上下限値整合性チェック | 上限値＜下限値で保存する                   | エラーメッセージが表示され、保存されない。 |
| 7   | レシピ読込             | アプリケーションを起動する                 | 保存済みレシピが正常に読み込まれる。       |

#### 状態遷移テスト

|  No | テスト内容 | 操作                                     | 期待結果                                                            |
| --: | ---------- | ---------------------------------------- | ------------------------------------------------------------------- |
|   1 | 情報送信   | メイン画面の「情報送信」ボタンを押下する | 状態が **READY** に遷移する。                                       |
|   2 | 測定開始   | メイン画面の「測定開始」ボタンを押下する | 状態が **START** に遷移し、測定シミュレーションが開始される。       |
|   3 | 測定終了   | 測定シミュレーションが完了する           | 状態が **COMPLETE** に遷移し、測定結果が CSV ファイルに出力される。 |
|   4 | 異常発生   | 異常を発生させる                         | 状態が **ERROR** に遷移し、エラーメッセージが表示される。           |
|   5 | リセット   | メイン画面の「リセット」ボタンを押下する | 状態が **IDLE** に戻る。                                            |

#### 測定機能テスト

|  No | テスト内容   | 操作                                                     | 期待結果                           |
| --: | ------------ | -------------------------------------------------------- | ---------------------------------- |
|   1 | 測定結果表示 | 測定シミュレーションを実行する                           | 測定結果がメイン画面に表示される。 |
|   2 | OK 判定      | 全体平均膜厚が上限値・下限値の範囲内となる測定を実施する | 判定結果が **OK** となる。         |
|   3 | NG 判定      | 全体平均膜厚が上限値または下限値を超える測定を実施する   | 判定結果が **NG** となる。         |

#### CSV 出力テスト

| No  | テスト内容               | 操作                                   | 期待結果                                                                                  |
| --- | ------------------------ | -------------------------------------- | ----------------------------------------------------------------------------------------- |
| 1   | CSV ファイル生成         | 測定シミュレーションを完了する         | CSV ファイルが指定フォルダへ出力される。                                                  |
| 2   | CSV ファイル名           | 測定シミュレーションを完了する         | ファイル名が仕様どおりで生成される。                                                      |
| 3   | CSV ヘッダー             | 出力された CSV を開く                  | ヘッダーが仕様どおり出力される。                                                          |
| 4   | 出力データ               | 出力された CSV を確認する              | CSV に出力された各項目が、画面に表示された測定結果と一致している。                        |
| 5   | CSV 出力件数確認         | 出力された CSV を確認する              | データ行数が選択したレシピの測定ライン数と一致する。                                      |
| 6   | 保存先フォルダ不存在     | 保存先フォルダを作成して測定を実行する | 保存先フォルダが作成されて CSV ファイルが出力される。                                     |
| 7   | 同一条件で複数回出力     | 続けて 2 回測定を実行する              | CSV ファイルが 2 つ生成され、既存ファイルが上書きされない。                               |
| 8   | CSV 出力失敗時の画面表示 | CSV 出力エラーを発生させる             | エラーメッセージが表示され、状態が **ERROR** に遷移し、「リセット」ボタンのみ活性となる。 |
