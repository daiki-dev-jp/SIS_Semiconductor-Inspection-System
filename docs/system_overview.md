#　システム概要

## 説明

本資料では、システム概要を示しています。
一部の機能は現在実装中であり、最新の実装状況については README の「開発状況」を参照してください。

## 概要

半導体検査装置を想定したデスクトップアプリです。

レシピの作成・読込を行い、
測定シミュレーションを実施し、
CSV を出力します。

出力した CSV は Web システムへ取り込み、
検査履歴や統計情報を表示します。

## シミュレーション仕様

本ポートフォリオでは、実機のラインスキャンを完全に再現することを目的とはしていません。

- 各ラインの代表値（平均膜厚）をシミュレーションデータとして生成
- 全ラインの代表値から全体平均膜厚を算出
- 全体平均膜厚を基に OK / NG を判定
- 測定結果を CSV として出力し、Web アプリで分析可能
